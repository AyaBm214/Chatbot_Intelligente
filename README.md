# Chatbot_Intelligente
# 🎓 Plateforme Étudiante – Gestion de FAQ, Deadlines & Chatbot

## 📌 Description
Cette application web a pour objectif d’accompagner les étudiants dans la gestion de leurs projets de fin d’études (PFE) en proposant :
- Une **FAQ dynamique** pour répondre aux questions fréquentes.
- Une **gestion des deadlines** (ajout, modification et suivi des échéances académiques).
- Un futur **module Chatbot** basé sur NLP (à venir).

Le projet est structuré en deux parties principales :
- **Backend** : API REST développée avec Spring Boot.
- **Frontend** : interface web développée avec React.js.
